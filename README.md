# Animaciones de Corazones en Python

Este repositorio contiene dos scripts de Python que utilizan la librería gráfica Turtle para crear animaciones artísticas y dinámicas de corazones con efectos visuales.

## Contenido del Repositorio

* `corazon.py`: Dibuja un corazón estructurado mediante un bucle geométrico con una paleta de colores degradados y líneas de transición[cite: 1].
* `purlple.py`: Genera una animación dinámica de partículas y trazos de múltiples tamaños con tonalidades púrpuras y rosadas que simulan un efecto estelar o de latido[cite: 2].

## Requisitos Previos

No necesitas instalar librerías externas complejas, ya que Turtle y Math vienen integrados por defecto en la biblioteca estándar de Python. 

Asegúrate de tener instalado:
* Python (versión 3.x recomendada).
