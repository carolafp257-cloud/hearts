# Animaciones de Corazones en Python

Este repositorio contiene dos scripts de Python que utilizan la librería gráfica Turtle para crear animaciones artísticas y dinámicas de corazones con efectos visuales.

## Contenido del Repositorio

* `corazon.py`: Dibuja un corazón con una paleta de colores degradados y líneas de transición.
* `purlple.py`: Genera una animación de partículas y trazos de múltiples tamaños con tonalidades púrpuras y rosadas.

## Requisitos Previos

No necesitas paquetes de `pip`, pero Turtle requiere **Tkinter/Tcl-Tk** y una sesión gráfica para abrir sus ventanas.

Asegúrate de tener instalado:
* Python (versión 3.x recomendada).
* Tkinter. Puedes comprobarlo ejecutando `python3 -m tkinter`.

Si falta Tkinter, en Debian/Ubuntu instálalo con:

```bash
sudo apt-get install python3-tk
```

## Cómo Ejecutar los Scripts

1. Clona este repositorio o descarga los archivos en tu computadora:
   ```bash
   git clone https://github.com/carolafp257-cloud/hearts.git
   cd hearts
   ```
2. Ejecuta la animación que quieras:
   ```bash
   python3 corazon.py
   # O bien:
   python3 purlple.py
   ```
